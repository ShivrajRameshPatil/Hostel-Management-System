# Hostel Management System

This is a Hostel Management System built using Python and MySQL. It allows students to register, log in via OTP, view hostel details, and manage their stay. The system also facilitates hostel employees in managing room allocations, tracking payments, and using face recognition for attendance.

## Features

- **New Student Registration**: Students can register by providing necessary details and payment information.
- **OTP Login**: Existing students can log in securely using OTP (One-Time Password) to view their details and hostel information.
- **Room Allocation**: Students can view available rooms and select one based on their requirements.
- **Payment Tracking**: Track payments, dues, and partial payments with ease.
- **Face Recognition for Attendance**: Use face recognition to identify students for attendance tracking.

## Tools and Technologies

- **Python**: Used for application logic and GUI development.
- **Tkinter**: Python GUI toolkit used for building the user interface.
- **MySQL**: Database management system used for storing student and hostel data.
- **OpenCV**: Used for face recognition and student identification.
- **MySQL Connector**: Python library used to connect the application to MySQL database.
