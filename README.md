Hostel Management System

Problem Definition:

A Hostel Management System built using Python and MySQL that allows students to register, log in via OTP, and view hostel details. The system also enables easy management by hostel employees, with features such as room booking, payment tracking, and face recognition for attendance.

Features:

New Student Registration: Students can register by providing details and payment information.
OTP Login: Existing students log in using OTP to view their details and hostel info.
Room Allocation: Students can select available rooms based on their requirements.
Payment Tracking: Easily track payments, dues, and partial payments.
Face Recognition: Used for student identification and attendance.

Tools and Technologies:

Python for the application logic and GUI (Tkinter).
MySQL for database management.
OpenCV for face recognition.
MySQL Connector for database connectivity.
